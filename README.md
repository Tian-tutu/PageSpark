# PageSpark

> AI-powered excerpts that bring you back to the page.

## 为什么做 PageSpark

很多人不是不想读书，而是书下载下来、收藏起来之后，就一直没有真正开始。书架越来越满，真正打开的书却越来越少。

视频从长视频走向短视频，音乐也从完整歌曲延伸出了“先听高潮片段”的触达方式；文字阅读却仍然常常要求读者先投入一段完整的时间。PageSpark 想做的，是给阅读增加一个轻量的入口：先在合适的时机展示一小段真正来自书里的文字，让人因为这句话产生兴趣，再一键回到它所在的章节。

它也尽量减少跨应用寻找和跳转带来的流失：从看到句子，到打开原文，中间不需要再搜索书名、重新找章节或切换多个平台。

## 它是怎么工作的

```text
告诉 PageSpark 想看的书
      ↓
解析正文与目录
      ↓
AI 判断书籍类型，按类型寻找更值得读的原文
      ↓
校验原文与章节位置，建立推荐池
      ↓
按选书范围和阅读偏好挑选书摘
      ↓
在合适时间主动展示
      ↓
点击书摘进入对应原文，阅读、划线或导出分享
      ↓
根据反馈调整推荐排序，持续推荐
```

## AI 在其中做什么

- 识别一本书更偏小说、纪实、方法论还是科普等类型。
- 根据书籍类型选择不同的“精彩”：小说更关注叙事张力与情绪，方法论更关注有启发的观点，科普更关注能改变理解的解释。
- 从原文中筛选完整、可独立阅读、能让人产生继续阅读意愿的段落。
- 校验句子确实来自书中，并记录它所在的章节，保证点击后能回到原文位置。
- 根据用户喜欢、跳过、划线和导出等行为，逐步调整后续推荐排序。

当前公开版本是一个可运行的 v2 演示：推荐池使用已经校验过的本地示例数据，运行时的动态 AI 识别与个性化排序仍在实现中。这样既能完整体验核心流程，也不会把“演示数据”误认为已经上线的云端 AI 服务。

## 当前版本可以体验什么

- Windows 桌面浮窗：可以拖动、置顶，并在设定时间主动展示书摘。
- 选定某一本书，或在全部书籍中随机推荐。
- 点击书摘进入对应 EPUB 原文，并定位到书摘所在章节/位置。
- 原文阅读时划线，划线会保存在本地，并以与书摘一致的视觉方式显示。
- 将当前书摘导出为 PNG 图片，方便收藏或分享。
- 内置 4 本示例 EPUB、每本 5 条已校验书摘，共 20 条推荐内容。

## 直接试用

打开仓库的 **Releases** 页面，下载最新的 Windows 安装包并安装即可。

如果只想查看源码或自行运行：

```powershell
pnpm install
pnpm start
```

## 仓库内容

```text
electron/       Electron 主进程、窗口与本地状态
src/            书摘浮窗、设置页与原文阅读界面
data/           4 本示例 EPUB、目录元数据与 20 条推荐书摘
assets/fonts/   书摘界面使用的 Huiwen 字体
scripts/        EPUB 解析、预览和桌面测试脚本
```

阅读记录、划线和设置保存在本机 Electron 用户目录，不会自动上传到仓库。
